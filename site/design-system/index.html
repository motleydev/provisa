Design system

Thirty components,
one stylesheet

Every component of the Provisa UI kit, ported to static HTML and CSS and rendered here from the partial a page would copy. Nothing on this page is written twice: each specimen is fetched from site/design-system/partials/ at load.

HOW TO READ IT Light is the default for every first-time visitor whatever their operating system is set to; the buttons above reach dark and persist the choice. Resize the window to check a component: the readout beside the title gives the current viewport width. The verified widths are 360, 768, 1280, 1920 and 2560.

The source picker

Generated into the marketing pages by scripts/gen-site-source-picker.mjs, which owns its class names. The design system styles them; it does not emit them. Shown here with three stand-in rows so the styling is reviewable without running the generator.
