Industries

Regulated work is a join problem. Provisa is the governed join.

A regulated team already has the data: a build registry and a vulnerability feed; positions and prices; an electronic record and a claims warehouse; an agency's own tables and a federal open-data feed. The question is who got to see what, under which rule, in which region, when a reviewer asks a month later. One model answers it across the four verticals this page lists.

The model's primitives are the same whether the vertical is cybersecurity, financial services, healthcare or government. A column names the roles that may see it. A row filter is injected before the engine runs the statement. A join must match a steward-approved relationship. A region on a table pins its whole-table copies to one cluster. Every governed query lands in an append-only audit log, written at the single pipeline every surface goes through.

Four verticals, one model

01

Cybersecurity

Non-compliant builds, cloud inventory joined to policy, and CVEs by application and deployment — each a query over tables the security team already has.

 02

Financial services

Positions and prices as views with history, deposits that stay in the country that holds them, and an audit record that keeps both the time the read used and the time the row was recorded.

 03

Healthcare

Opt-in filters on research reads, PHI columns absent from the researcher's schema, and one audit log over every surface — SQL, GraphQL and Cypher alike.

 04

Government

Agency-by-agency domains, row filters on classification level, and regional clusters on one shared model — home data stays with its home region's cluster.

The governance, named once

01

Column visibility

A column names the roles that may see it. A role granted no visible column on a table has that table dropped from its schema. A column it was never granted is not a column it can discover.
02

Regions

Each region runs its own engine, storage and cache on one shared model. A table may name a home region; its whole-table copies live only there, and reads from other regions are served in place under the reader's rules.
03

Audit

Every governed query writes one row to an append-only log — the user, the role, the tables touched, the surface, the status, the duration and what was enforced. The query text is stored as a hash, never in the clear.
04

Masking

A masked column comes back transformed — redacted, truncated or substituted — and the mask is a projection in the governed IR. Where the source can evaluate it, the mask pushes down and the raw value never crosses the wire.
