Use Cases · Enterprise SaaS and Workflow

The systems where work happens. Joined and governed.

ServiceNow, Salesforce, SharePoint, Microsoft 365 and Google Workspace joined to the warehouse, read and written under one model, with every change audited. IT operations wants incidents beside metrics, logs, deploys and resources. Renewals managers want accounts beside escalations. HR onboarding creates tickets and calendar events. Executive assistants prepare meetings with attendees' opportunities and tasks. Analysts join quotes to custom discount functions.

ServiceNow, Salesforce, SharePoint, M365 and Google Workspace sources, each joined through approved relationships. Writes go through the governed pipeline and land in the audit log. The Node connector turns exported TypeScript functions into queryable tables.

01ServiceNow + observability

IT operations wants every open P1 incident beside what is actually happening to the affected service.

ServiceNow source gives the incident, its affected service from the CMDB, and the service's change requests. The same service is joined to Prometheus metrics, Splunk logs since the incident opened, deploys from GitHub, and AWS/Azure/GCP resources from the Cloud Inventory source. One governed query answers it. The dashboard reads over GraphQL, and an on-call agent works through MCP, posting findings back to the incident through the ServiceNow write route.

02Salesforce + ServiceNow

A renewals manager wants accounts renewing next quarter that have open support escalations, and to flag each at-risk deal in Salesforce.

Salesforce and ServiceNow sources joined on the account in one governed query. The flag is written back to the Salesforce opportunity through Provisa's write route, checked against the manager's rights and recorded in the audit log, with no integration job to build.

03HR onboarding automation

When a new hire is approved, IT needs a laptop request in ServiceNow and the hire needs first-week meetings on their calendar.

A command calls ServiceNow's Import Set API, so the request goes through the instance's own transform map and validation. Calendar events are created through the M365 or Google Workspace source. Both run under the HR role's rights and are audited.

04Executive assistant agent

An executive assistant agent prepares the week: tomorrow's meetings with each attendee's open opportunities and overdue tasks.

M365 and Google Workspace calendars and tasks, read and written, joined to Salesforce. A row filter keeps each user to their own calendar and tasks. The agent works through MCP; every write is audited.

05Audit trail compliance

Internal audit must show that every production change last quarter had an approved change request and an evidence document filed.

ServiceNow change requests joined to the SharePoint document library's metadata. A view lists changes missing approval or evidence, and a data-quality checker runs it on a schedule, keeping each run's results as the audit trail.

06Field service with IoT

A technician's tablet shows the asset's recent sensor readings and the three most relevant repair procedures for the fault on the open work order.

ServiceNow work orders, Azure Cosmos DB telemetry and a MongoDB pipeline table running Atlas vector search over the manuals, with the fault text passed as a required parameter. Joined in one governed query for the app.

07Node connector

A pricing team's discount rules live in TypeScript code that no SQL tool can call, but analysts need the effective discount beside every quote.

The Node connector: an exported function tagged @table becomes a table whose arguments are parameters and whose return type gives its columns. Analysts join it to Salesforce quotes in SQL, under the same governance as any table.
